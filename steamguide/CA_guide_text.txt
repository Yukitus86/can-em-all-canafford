# ===== TITLE =====
CanAfford – See Every Skill You Can Buy Right Now (Skill Tree Mod)

# ===== DESCRIPTION =====
Free MelonLoader mod: every skill you can afford right now lights up in the skill tree – neon green, red border and the price in the middle. Updates live when your money changes. No more searching the whole tree. Your save is never touched.

# SECTION 1 – title:
Overview
############################################################################

[IMAGE: CA_01_tree.png]

[h1]What is this?[/h1]
A small mod for [b]Can 'Em All[/b] that marks every skill you can buy [b]right now[/b] in the skill tree:
[list]
[*][b]Neon green[/b] node with a [b]red border[/b]
[*]The [b]price[/b] in the middle instead of the icon – $850, $1,000, $25K, $1.5M
[*]Gently pulsing, so you spot it even when zoomed out
[*]Updates [b]live[/b] when your money changes or you buy a skill
[/list]

"Can buy right now" means: not bought yet, all required skills bought, and the price is not higher than your current money – exactly the game's own rules.

[IMAGE: CA_02_comparison.png]

[list]
[*]Free and open source (MIT licence)
[*]Only changes how the skill tree looks – [b]your save is never touched[/b]
[*]Works with any savegame, turn it off anytime with [b]F7[/b]
[/list]

[i]Unofficial fan mod, not affiliated with LuisDev.[/i]

# SECTION 2 – title:
Installation
############################################################################

[h1]1. Install MelonLoader (once)[/h1]
CanAfford is a [b]MelonLoader[/b] mod – the standard open-source mod loader for Unity games.
[olist]
[*]Download [b]MelonLoader.Installer.exe[/b] from [url=https://github.com/LavaGang/MelonLoader/releases]github.com/LavaGang/MelonLoader/releases[/url] (version 0.7.3 or newer).
[*]In Steam: right-click [b]Can 'Em All[/b] → [b]Manage[/b] → [b]Browse local files[/b]. That's your game folder.
[*]Start the installer, select [b]Can 'Em All.exe[/b] from that folder and click [b]Install[/b].
[*]Start the game once. A console window opens and MelonLoader sets itself up (takes about a minute). Then quit the game.
[/olist]

[h1]2. Install CanAfford[/h1]
[olist]
[*]Download [b]CanAfford-x.y.z.zip[/b] from the latest release:
[url=https://github.com/Yukitus86/can-em-all-canafford/releases/latest]github.com/Yukitus86/can-em-all-canafford/releases/latest[/url]
[*]Unzip it and copy [b]CanAfford.dll[/b] into the [b]Mods[/b] folder inside your game folder.
[*]Start the game. The MelonLoader console shows [b]CanAfford loaded[/b].
[/olist]

[h2]Uninstall[/h2]
Delete [b]Mods\CanAfford.dll[/b]. To remove MelonLoader completely, delete [b]version.dll[/b], [b]MelonLoader[/b], [b]Mods[/b], [b]Plugins[/b], [b]UserData[/b] and [b]UserLibs[/b] from the game folder.

[h1]FAQ[/h1]

[b]Nothing happens / no "CanAfford loaded" in the console.[/b]
Check that MelonLoader is installed (a console window opens when the game starts) and that CanAfford.dll is directly in the [b]Mods[/b] folder, not in a subfolder.

[b]Does it change my save or give me money?[/b]
No. It only colors the skill tree. Nothing is written to your save.

[b]A green node without a price?[/b]
Then the game itself colors that branch green (bought skills). Affordable skills always show their price and the red border.

[b]Does it work with the demo?[/b]
It is made and tested for the full game.

[b]The game was updated and the mod stopped working.[/b]
Leave a comment or open an issue on GitHub – I'll update it.
